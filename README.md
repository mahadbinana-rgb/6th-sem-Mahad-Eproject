EarthScape Climate Intelligence ReadMe

Technology: Python, Flask, MongoDB, HTML, CSS, vanilla JavaScript.
Intentionally excluded: React, Node.js, Hadoop, HDFS, MapReduce and Impala.

Purpose: ingest, process, analyze and visualize climate information; detect anomalies; forecast trends; provide alerts, support, monitoring, backups and role-based access.

Start:
1. Create and activate a Python virtual environment.
2. Install requirements.txt.
3. Copy .env.example to .env and configure MongoDB.
4. Run: python seed.py
5. Run: python app.py
6. Browse to http://127.0.0.1:5000

Default administrator: admin / admin123 (change it before non-demo use).
